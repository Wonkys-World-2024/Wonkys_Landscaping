# Third-party assets — redistribution not verified

The original v0.29.0 ZIP contains files under `stream/` including Bzzz garden, lumberjack and waste-bag props, textures and archetypes. These are intentionally excluded from this public source-review package because permission to redistribute them has not been established.

The manifest does not bundle or register Bzzz YTYP files. Install the original creator-provided resources separately and ensure their archetypes are registered.

Other files to review before public redistribution: `web/wonkys_landscaping_logo.png`, `web/strimmer_loop.wav`, and any code or graphics copied from other resources. No license information was supplied for these files.

Do not claim these files are MIT/GPL/open-source merely because they can be downloaded for free. Link to original authors and follow their redistribution terms.
